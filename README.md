# Тестовое задание для направления Backend разработка

Реализация тестового задания на позицию Beckend-разработки от Greensight.

Исходное задание: https://github.com/Hexlet/ru-test-assignments/blob/main/backend/greensight/README.md

## Описание задачи

1. Создать страницу с формой со следующим запросом данных:
    - Имя
    - Фамилия
    - email
    - Пароль
    - Повтор пароля.

2. Реализовать отправку этой формы при помощи AJAX.
3. Реализовать обработку AJAX запроса на php.

## Что сделано 

1. Создана форма с запросом необходимых данных.
2. Реализована отправка формы через AJAX и обработка этого запроса на Java.
3. Реализована проверка вводимых данных.
4. Запись результатов в лог-файл
5. Вывод сообщений об ошибках и успешной регистрации.

## Что не сделано

1. Программа написана на Java вместо PHP из-за недостатка знаний.
2. Вместо базы данных пользователи хранятся в массиве (разрешенно заданием).

## Как запустить программу

**Требования**: Установленой JDK 17 версии или выше.

### Запуск через терминал:
1. Скачать проект и распаковать архив.
2. Открыть терминал в корневой папке ```greensight-java.```
3. Скомпилировать исходные файлы: ```javac -d out src/main/java/greensight/*.java```
4. Запустить сервер: ```java -cp out greensight.Main```
5. Открыть в браузере страницу: ```http://localhost:8081```
Остановить сервер можно сочетанием клавиш Ctrl + C в терминале.
